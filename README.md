# LoopX

**LoopX** is a solo‑built, full‑stack Flutter social app that merges the best bits of Threads‑style micro‑posting, Instagram‑style media sharing, and real‑time DMs— all powered by Supabase.

- [ ] **Direct Messaging**  
- [ ] **Explore / Trending**  
- [ ] **Notifications & Push**
